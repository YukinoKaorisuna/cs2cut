## 三、换选手

编辑 `config.json`：

```json
{
  "players": [
    { "nickname": "donk666", "expect_elo": 4500 },
    { "nickname": "dem0nnnnnnnn", "expect_elo": 4500 }
  ],
  "match_limit": 30,
  "min_kills": 25
}
```

`expect_elo` 用来**防同名假号**——如果查到的 Elo 低于这个值会警告。
不填就写纯字符串 `"donk666"`。

**怎么找选手昵称？** 打开 https://www.faceit.com 首页，底部有全球排行榜，
前几名就是顶尖选手。或者直接访问 `https://www.faceit.com/en/players/{昵称}` 确认。

## 五、⚠️ demo 下载：代理配置（当前唯一阻塞）

### 问题现象

demo 文件存在 `*.backblaze.faceit-cdn.net`，实测：

| 方式 | 结果 |
|---|---|
| 走代理 | HTTP 502（节点不通） |
| 直连 | DNS 解析失败 |

### 解决办法（需要你在 Clash Verge 里操作）

**方案 1：给该域名指定可用节点（推荐）**

Clash Verge → 订阅 → 编辑规则，在 `rules` 里加一条（放在前面）：

```yaml
rules:
  - DOMAIN-SUFFIX,backblaze.faceit-cdn.net,你的节点名
  # ... 其他规则
```

试试不同节点，找一个能通的。

**方案 2：直连该域名**

如果该 CDN 在国内可直连：

```yaml
rules:
  - DOMAIN-SUFFIX,backblaze.faceit-cdn.net,DIRECT
```

但这个 CDN 是 Backblaze，国内大概率需要代理。

**方案 3：换个能通的节点**

用 Clash 的节点测速功能，逐个测试，找能访问该域名的节点。

### 验证是否修好

```powershell
python src\fetch_demos.py --probe-only --limit 3
```

显示 `[OK]` 就说明通了。

## 六、下载 demo

```powershell
# 下载所有 >=25 杀的场次
python src\fetch_demos.py

# 只下 donk666 的
python src\fetch_demos.py --player donk666

# 只下 >=30 杀，且最多 5 个
python src\fetch_demos.py --min-kills 30 --limit 5
```

demo 存到 `demos/`，单场约 100~300 MB。**下载支持断点续传**，中断了重跑即可。

## 七、解析多杀（3K/4K/5K）

```powershell
# 先装解析库
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple demoparser2

# 解析所有已下载 demo
python src\parse_demos.py

# 只找 4K 以上
python src\parse_demos.py --min-kills 4

# 解析单个 demo
python src\parse_demos.py --demo "demos\xxx.dem.zst"
```

会自动解压 `.zst`、解析击杀事件、回填到 `data/*.json`，再跑一次 `dashboard.py` 就能看到多杀标签。

## 九、常见问题

**Q：查不到选手 / Elo 很低？**
FACEIT 昵称大小写敏感，且有大量同名号。确认 Elo 对不对（顶尖选手 4000+）。

**Q：demo 链接为空？**
- 该场 demo 已过 30 天有效期
- 或该场不是正式比赛

**Q：3K/4K/5K 显示为空？**
正常。FACEIT 公开接口没有多杀数据，**必须下载 demo 并解析**后才有。
先解决代理问题 → 下载 demo → 跑 `parse_demos.py`。

**Q：被限流 / 403？**
降低 `config.json` 里 `rate_limit.requests_per_second`（改成 1）。
